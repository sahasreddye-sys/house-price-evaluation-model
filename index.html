      How close does it get?

      Every estimate on this site is out-of-fold: the model that priced a home never saw that home while training. These scores compare those estimates with the county’s own assessed values.

      What’s new in v2

      The first version priced Alpharetta homes from four inputs and covered a 1,653-home sample of Cumming. This one reads each home’s actual building, covers all of Forsyth County, and puts a tested range on every estimate.

      1. Building details for AlpharettaSquare footage across every structure, year built, beds, baths, stories, basement, exterior, fireplaces, lot topography and road frontage.
      2. All of Forsyth County80,306 homes instead of a 1,653-home sample from Cumming.
      3. Dropped the county’s land valuev1 leaned on the assessor’s own land value, which a buyer can’t supply. With the new inputs, v2 lands within 0.1 points of v1’s median error without it.
      4. Location from coordinatesLatitude and longitude, so the model can tell apart streets inside the same neighborhood code.
      5. A range you can trustThe 80% range comes from the model’s real errors, then gets checked on a held-out half of homes: 79.8% and 80.0% coverage.
      6. A tougher testHolding out entire neighborhoods shows how the model does somewhere it has never seen, not only on the neighbors of homes it trained on.
